# Sprachen: Deutsch, Englisch, Spanisch

Deutsch ist die Quellsprache: Jeder Text steht deutsch im Code und wird über `t("…")` (App, `src/lib/i18n.tsx`)
bzw. `msg("…")`/Fehlerklassen (Server und gemeinsamer Kern, `src/i18n/index.ts`) übersetzt. Die Wörterbücher liegen
in `src/i18n/dict/<bereich>.ts` (Schlüssel = deutscher Originaltext). `test/i18n.test.ts` prüft, dass jeder Text
im Code auf Englisch und Spanisch vorhanden ist, mit denselben Platzhaltern (`{name}`) und Auszeichnungen (`<b>`).

Regeln:

- Texte immer als Literal: `t("Du schuldest · {amount}", { amount: formatMoney(…) })` – nie aus Stücken bauen.
- Fett/kursiv im Satz: `rich(t("Tippe auf <b>„Teilen“</b>"))` (erlaubt: `b`, `strong`, `i`, `em`, `small`, `br`).
- Beträge in Server-Texten als `{ cents, currency }`, damit sie im Format des Lesers erscheinen.
- Englisch: natürlich und knapp, „you“. Spanisch: Spanien, „tú“ (klein, wie im Spanischen üblich), Anführungszeichen
  « ». Englisch “ ”.
- „klicksplit“ wird nie übersetzt.
